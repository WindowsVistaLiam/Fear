SITE RP — FEAR, FLÉAU CLASSE S

Ce dossier contient un site complet en HTML/CSS/JS pour une fiche RP Discord écrite dans un univers inspiré JJK.

Infos déjà intégrées :
- Nom : Fear
- Nature : Fléau
- Rang : Classe S
- Rôle : Antagoniste
- Apparence : inspirée d’Evelynn de League of Legends
- Palette : violet, magenta, rose néon, noir profond
- Ambiance : sombre, séductrice, maudite, prédatrice

Pages :
- index.html : accueil
- profil.html : identité, apparence, personnalité
- pouvoirs.html : sort inné, techniques, domaine, faiblesses
- histoire.html : origine et objectif RP
- relations.html : liens RP
- notes-rp.html : conseils pour jouer Fear

Utilisation :
1. Dézippe le fichier.
2. Ouvre index.html dans ton navigateur.
3. Modifie les textes directement dans les fichiers HTML.
4. Le style se trouve dans assets/css/style.css.
5. Les effets dynamiques se trouvent dans assets/js/main.js.

Le site n’utilise aucune image externe : tout repose sur le design, les couleurs et les effets.
